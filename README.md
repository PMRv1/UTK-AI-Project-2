# AI101-Assignment3
# This project demonstrates how I used Google Gemini to assist with data analysis, visualization, and machine learning across two tasks. In Task 1, I worked with finance_data.csv by loading it from Google Drive, exploring its structure (data types, summary statistics, and missing values), and cleaning the dataset by removing rows with null values to ensure consistency. I created visualizations including a scatter plot of profit vs. revenue and a correlation matrix to better understand relationships between variables, identifying which features had strong positive or negative correlations. Using these insights, I built a Linear Regression model to predict stock price as the target variable, splitting the data into training and testing sets before fitting the model. To evaluate performance, I generated 100 random data points; initially, the values were unrealistic, so I refined my prompt to ensure the generated data matched the same order of magnitude as the original dataset. With this improved data, I made predictions, visualized the predicted stock prices, and observed that while the overall trends were similar to the original dataset, some variation existed due to the synthetic nature of the test data. In Task 2, I repeated the full workflow using the Hitters.csv dataset, adapting preprocessing steps such as handling missing values and selecting an appropriate target variable based on the dataset’s structure, then rebuilding and testing a regression model in the same way. Throughout the assignment, Gemini was used to generate and refine code through natural language prompts, demonstrating that more specific and detailed prompts lead to more accurate and usable outputs. Key takeaways include the importance of proper data cleaning, the value of visualization and correlation analysis in understanding data, and the need to verify and interpret AI-generated code rather than relying on it blindly. Challenges included resolving file path issues when loading data, correcting assumptions made by Gemini, generating realistic synthetic test data, and adapting the workflow to a different dataset. Overall, this assignment shows how AI can significantly improve efficiency while still requiring critical thinking to ensure accurate results.
